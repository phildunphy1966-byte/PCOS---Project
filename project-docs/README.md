# PCOS Unlocked — Google AI Studio Website Package

**Tagline:** Understand your body. Question the myths. Find your way forward.

This is the complete GitHub-ready project brief, structured JSON configuration, master prompt, research/source register and original SVG diagram set for generating the PCOS Unlocked website in Google AI Studio.

## What's included
- `01_PROJECT_BRIEF/` — complete dossier with research context, audience, IA, sitemap, task/user flows, page requirements, visual direction and QA checklist.
- `02_JSON_CONFIG/` — separate project, content, route, design-system and interaction JSON files.
- `03_PROMPTS/` — standalone Google AI Studio master prompt and import/build instructions.
- `04_RESEARCH/` — dataset/primary-research limitations and source register.
- `05_ASSETS/diagrams/` — original SVG educational diagrams for local use.
- `06_GITHUB_SETUP/` — GitHub import checklist.

## Brand and audience
PCOS Unlocked is an India-context PCOS awareness and body-literacy platform. It prioritises young women aged 18–25 while supporting six optional age bands (Under 18, 18–21, 22–25, 26–30, 31–35, Above 35). It includes a female learning path, a male ally path and an Explore Everything path. The male path is educational ally content only; it must never suggest that males have PCOS.

## Start here
1. Read `03_PROMPTS/BUILD_INSTRUCTIONS.md`.
2. Import this repository into Google AI Studio.
3. Supply the dossier, JSON files and SVG assets as context.
4. Paste `03_PROMPTS/GOOGLE_AI_STUDIO_MASTER_PROMPT.md`.
5. Require implementation and testing of every route.

## Medical and research safeguards
This is an educational project, not a diagnostic tool. Do not add symptom checkers, diagnosis scores, medication dosing or cure claims. Do not collect sensitive health information. The supplied datasets are exploratory and have limitations; do not use them to claim Indian prevalence or to compare male/female awareness. The known female Google Forms sample is 49 respondents; do not fabricate findings or male sample size. Use actual response exports for any charts. Qualified clinical review is required before public launch.

## Files are specifications, not a finished deployed app
Google AI Studio must still generate the React/frontend implementation. The included files define what to build and provide local diagrams; they do not claim that a website is already running.
